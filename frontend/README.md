# 🛡️ SentinelAI – AI Powered Industrial Safety Monitoring System

An AI-powered Industrial Safety Monitoring Platform built using **FastAPI**, **React**, **SQLite**, and **Machine Learning based Risk Analysis**.

The system continuously monitors industrial sensors, detects abnormal conditions, generates AI-powered risk assessments, and recommends safety actions in real time.

# 🤖 AI Decision Engine

The AI Engine analyses all sensor readings and generates:

- Risk Score
- Risk Level
- Hazard Detection
- Emergency Probability
- AI Recommendations

Example:

Risk Level : EXTREME

Recommendation :

🚨 Shutdown Plant Immediately

# ⚙️ Installation

## Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

## Frontend

```bash
cd frontend

npm install

npm run dev
```
