# SentinelAI

AI-Powered Industrial Safety Monitoring System

## Features

- Real-Time Industrial Sensor Monitoring
- AI-Based Risk Analysis
- Live Dashboard
- Automatic Alert Generation
- Incident Detection
- SQLite Database
- FastAPI Backend
- React + Vite Frontend

## Tech Stack

### Backend
- FastAPI
- SQLAlchemy
- SQLite

### Frontend
- React
- Vite
- Tailwind CSS

## Run Backend

```bash
uvicorn app.main:app --reload
```

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```
